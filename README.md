# Практическая работа №2 — Заметки

Flutter-приложение по ТЗ практической работы.

Реализовано ровно требуемое для оценки 5:
- ввод текста заметки;
- сохранение заметки в список;
- удаление заметки;
- редактирование существующей заметки.

Заметки хранятся в памяти приложения. Сохранение между запусками ТЗ не требует.

## Запуск на Mac / iPhone Simulator

Открыть папку проекта в VS Code.

Если папка получена из ZIP впервые и платформенные файлы Flutter ещё не созданы, в Terminal внутри проекта выполнить:

```bash
flutter create .
flutter pub get
```

После этого выбрать iPhone Simulator в VS Code и нажать Run или выполнить:

```bash
flutter run -d "iPhone 18 Pro"
```

Для открытия iOS-проекта в Xcode использовать:

```bash
open ios/Runner.xcworkspace
```
